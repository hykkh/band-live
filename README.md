# band-live

네이버 밴드 라이브 예배에 정해진 요일·시각마다 자동으로 들어가 무음으로 시청하고, 방송이 끝나면 닫는 프로그램.

- 관리 화면: http://127.0.0.1:7960 — 켜기/끄기, 이번 한 번 건너뛰기, 지금 들어가기/끄기, 로그인 창, 시간 설정
- 처음 한 번: 관리 화면에서 **로그인 창 열기** → 뜬 창에서 밴드에 직접 로그인("로그인 상태 유지" 체크)
- 알림: 텔레그램으로 입장 완료 / 종료(시청 시간·사유) / 라이브 없음 / 로그인 풀림

Python 3.12 · Flask · Chrome DevTools Protocol(Edge). 자세한 것은 [CLAUDE.md](CLAUDE.md).
